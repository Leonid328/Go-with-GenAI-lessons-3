# Промпт для виокремлення інтерфейсу (Розділ 2)

## Мій промпт

Ти досвідчений Go розробник. Є сервіс замовлень, який зараз ходить напряму в *sql.DB. Мені треба маленький інтерфейс, без зайвих методів.

Код зараз такий: OrderService має метод PlaceOrder(orderID string, amount float64), всередині має бути виклик store.Exec(query, orderID, amount).

Зроби так:
1. інтерфейс OrderStore тільки з Exec(query string, args ...any) error
2. OrderService приймає OrderStore через конструктор NewOrderService
3. мок для тестів без реальної бази

Не роби великий інтерфейс. Приказка Пайка: чим більший інтерфейс, тим слабша абстракція.

Поверни тільки Go код, три блоки: інтерфейс, сервіс, мок.
